# ISO-5055 CWE-480 Compliance Microagent

## Purpose
This agent ensures compliance with ISO-5055, specifically the rule:

**CWE-480 - Use of Incorrect Operator**
- **Rule:** Avoid explicit comparison with NULL
- **Description:** Comparisons with NULL can never result in either True or False, but always in a third logical result, Unknown.

## Guidance
- Do **not** use explicit comparisons to NULL (e.g., `if (x == NULL)` or `if (x != NULL)`).
- Use language-appropriate idioms for null checks (e.g., `if (x)` in C/C++, or `if x is None` in Python).
- Review code for any explicit `== NULL` or `!= NULL` comparisons and refactor to avoid them.

## Usage Example
- **Bad:**
  ```c
  if (ptr == NULL) { /* ... */ }
  ```
- **Good:**
  ```c
  if (!ptr) { /* ... */ }
  ```

## Limitations
- This agent only checks for explicit NULL comparisons, not all possible null dereference issues.
- Language-specific idioms may vary; always follow best practices for the language in use.

## Error Handling
- If explicit NULL comparisons are found, flag them for review and suggest idiomatic alternatives.
